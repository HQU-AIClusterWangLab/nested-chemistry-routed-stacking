# Data Boundary

This directory contains no dataset.

The research workflow consumes private, authorized inputs that include cluster geometries, energies and forces, system identifiers, and post-DFT analysis products. Do not add those materials to this repository.

For a local reproduction attempt, maintain private data outside the clone and configure the relevant script paths or environment variables locally. Generated checkpoints, logs, ranking tables, DFT inputs and outputs, cube files, and figure exports must likewise remain outside version control.
